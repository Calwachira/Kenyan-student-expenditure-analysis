KENYAN STUDENT LIFE DASHBOARD

1. Install Python 3.9+ from https://www.python.org/downloads/
   (Windows: tick "Add Python to PATH" during install)
2. Start the app:
   - Windows: double-click "Start App (Windows).bat"
   - Mac:     double-click "Start App (Mac-Linux).command"
              (if blocked: right-click > Open, or run: chmod +x "Start App (Mac-Linux).command")
   - Any OS:  open a terminal in this folder and run: python start_app.py
3. Your browser opens at http://localhost:8501. The first run takes about a minute.

Background picture: save a USIU-Africa photo here as usiu_background.jpg
(or upload it from the sidebar inside the app).
